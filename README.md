# Portfolio Syahdan Aqilla

Portfolio pribadi Syahdan Aqilla, Software Engineer (Full Stack Developer Intern) dan mahasiswa D4 Teknik Informatika Politeknik Caltex Riau.

Dibangun dengan React 19, Vite, dan Tailwind CSS 4.

## Menjalankan

```bash
npm install
npm run dev
```

## Build produksi

```bash
npm run build
```

Hasil build ada di folder `dist`. Proyek ini bisa langsung dideploy ke Vercel (preset Vite).

## Struktur

- `src/sections` bagian halaman (Hero, Tentang, Pengalaman, Karya, Sertifikat, Skill, Kontak)
- `src/components` komponen (kartu nama, splash screen, lightbox, dll.)
- `src/data` isi portfolio (profil, project, pengalaman, sertifikat, skill)
- `public` gambar dan favicon
